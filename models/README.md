# Model and checkpoint index

No model binary is published. The repository records only the nine formal checkpoint identities, metrics, and
SHA256 values needed to audit independent-seed counting.

- `MODEL_INDEX.csv`: metadata-only index for EsMoE n=3, MoA n=1, and MoT n=5.
- `MODEL_CARD.md`: task, protocol, intended use, and limitations.
- `CHECKPOINT_POLICY.md`: publication gate and exclusion rationale.

See `results/tables/checkpoint_index.csv` for the matching formal result view.
