# Dataset policy

The formal experiments use VisDrone2019-DET. This repository includes no image, annotation, cache, archive, or
derived dataset package.

Users must obtain VisDrone from its official maintainers, review the applicable terms, and configure
`${DATASET_ROOT}` locally. Dataset licensing and provenance are separate from this repository's AGPL-3.0 license.
The public YAML under `configs/` is a path template, not a dataset mirror.
