# Contributions

This portfolio separates three layers of work.

## Upstream-provided foundation

Tencent/YOLO-Master and Ultralytics provide the detector framework, model definitions, engine, utilities, and open
source context. Their work retains its original ownership and license.

## Personal Issue #54 contribution

The audited branch records experiment schemas, registry/checkpoint integrity, routing export/alignment/metrics,
formal serial queues, architecture controls, compatibility fixes, tests, reports, and provenance. Personal changes
to upstream-derived files are `user_modified_upstream`; newly added research scripts/tests are `user_added`.

## Portfolio contribution

This repository adds compact public derivatives, deterministic figures, bilingual interpretation, public/private
artifact policy, model metadata, file-level provenance, validators, and reproducibility navigation.

Generated artifacts are not treated as hand-authored experimental observations: each is linked to a formal source
hash or public table. See [SOURCE_MANIFEST.csv](../provenance/SOURCE_MANIFEST.csv),
[Issue #54 record](../contributions/ISSUE_54.md), [PR #216 record](../contributions/PR_216.md), and
[commit map](../contributions/COMMIT_MAP.md).
