# Documentation index

Choose a reading path based on the decision you need to make.

## Five-minute orientation

1. Read the [English](../README.md) or [Chinese](../README_CN.md) landing page.
2. Inspect the three homepage figures and the main evidence-bounded conclusion.
3. Check the dated [PR #216 status](../provenance/PR_STATUS.md).

## Fifteen-minute result review

1. Read [Research question](RESEARCH_QUESTION.md).
2. Review [Routing stability](ROUTING_STABILITY.md) and [Architecture controls](ARCHITECTURE_CONTROLS.md).
3. Read [Results and limitations](RESULTS_AND_LIMITATIONS.md) before reusing a claim.
4. Inspect the compact [result tables](../results/README.md).

## Complete technical audit

1. Establish ownership and scope in [Project context](PROJECT_CONTEXT.md).
2. Read [Methods](METHODS.md) and [Experiment protocol](EXPERIMENT_PROTOCOL.md).
3. Trace hashes through the [formal evidence index](../provenance/FORMAL_EVIDENCE_INDEX.md),
   [source manifest](../provenance/SOURCE_MANIFEST.csv), and [report manifest](../results/manifests/REPORT_MANIFEST.json).
4. Review [contributions](../contributions/README.md), the [commit map](../contributions/COMMIT_MAP.md), and exact
   [patches](../patches/README.md).
5. Run the offline [reproduction and validation workflow](REPRODUCTION.md).
