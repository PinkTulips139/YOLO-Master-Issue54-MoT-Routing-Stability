# GitHub Social Preview setup

The deterministic image is stored at `docs/assets/social-preview.png`. Setting it as the repository Social Preview
requires one manual GitHub UI action:

1. Open <https://github.com/PinkTulips139/YOLO-Master-Issue54-MoT-Routing-Stability>.
2. Select **Settings**.
3. Under **General**, find **Social preview**.
4. Select **Edit**.
5. Upload `docs/assets/social-preview.png`.
6. Select **Save**.

The file being present in Git does not mean the GitHub repository setting has already been changed.
